# Site audit: first read (desktop screenshots, Nov 2 2026)

Site: "topten ratings" — Best Home Security Systems of 2026. Paid search (Google, Bing), mobile-only traffic today. Screens received are desktop; mobile still needed.

## What's on the page
- Hero: "Last updated November 2026", H1 "Best Home Security Systems of 2026", "Your family's safety, watched over 24/7", generic paragraph, family stock photo.
- "Our top 3 picks" strip: Vivint 9.4 / ADT 9.9 "We recommend" (center) / Brinks 9.2. Each shows only an offer (gift card, free doorbell) + Visit Site.
- Ranked list (6): ADT 9.9, Vivint 9.4, Brinks 9.2, Cove 8.7, Frontpoint 8.4, ADT blu 8.1.
  - Card: logo + product image, name, tagline, bold offer bullet, 2–3 ✓ bullets, score + stars, Visit Site button + "Get Protected" link.

- Fine print under ADT: min purchase $599 + 36-month monitoring from $34.99, early cancel fees, money-back conditions.
- Sticky bottom bar: ADT 9.9 + offer + Visit Site.
- Sidebar: "2,864 Homeowners chose a provider via Top10ratings this month", Editor's picks (ADT, Vivint, Brinks, Cove, Frontpoint), ADT banner "Secure your home around the clock", How we rate (CSS / BDI / EES accordions).
- FAQ (6): pick provider, is pro monitoring worth it, equipment, DIY install, insurance discount, wireless reliability. Then "What is home security?" content.

## First observations (to check against buyer research)
1. Real cost and contract are hidden in fine print (ADT: $599 min + 36-month contract + early cancel fees) while the card leads with a $100 gift card. Same pattern as weight-loss intro prices.
2. No card shows the monthly monitoring price (except Cove "< $1/day"), contract length, install type, or cancel terms — the facts buyers compare on.
3. Order favours pro-install contract brands (ADT, Vivint, Brinks) over no-contract options (Cove, ADT blu) — buyer-friendliest facts sit at #4 and #6.
4. SimpliSafe and Ring, the biggest DIY brands, are absent. Fine if no partnership, but the page doesn't serve "no contract / DIY" searchers well.
5. Install type label ("Professional install") only on #1. A DIY vs pro split / filter is the natural first question.
6. Two CTAs per card (Visit Site + Get Protected) — check if they differ; one clear CTA is usually better.
7. Social-proof widgets ("526 people visited today", "2,864 homeowners this month") — fine if real; verify they're not static.
8. Vivint bullet "Flexible financing" hides that equipment is financed over a contract.
9. Hero is generic; no help choosing (owner/renter, DIY/pro, budget).
10. Desktop shown; traffic is mobile — need mobile screens (card height, sticky bar, what's above the fold).
